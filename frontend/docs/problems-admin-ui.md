Ở phần Problems trong giao diện quản lý của admin, thì tôi muốn chia ra làm các phần như sau
- Danh sách kho lữu trữ các bài tạp nhưng chưa Active (là khi tạo xong 1 problem thì problems đó chưa có phần testcase thì problem đó sẻ chưa dc active)
- Tiêp theo là danh sách kho lưu trữ cac bài tạp đã active(khi mà admin add test case cho problem thì problem đó sẻ dc active) nhưng mà chưa public
- Ở phần hiển thị danh sách isAcive thì sẻ có phần admin cấp phép cho problems đó là scope practice hoặc contest

1 problem tôi muốn hiển thị gồm Title, Scope, difficutly, tổng số lần submission , acceptedRate (tính theo công thức số lần accepted / tổng số lần submission), isPublic
